# 马恩列斯毛原著定位器

输入中文关键词，定位马克思、恩格斯、列宁、斯大林、毛泽东已收录原著中的具体段落。[打开在线版本](https://zenzenzense520-bit.github.io/contradiction-analyzer/)，也可下载整个仓库后双击 `index.html` 离线使用。

结果显示作者、作品、网页标题、索引段落、中文上下文和原网页链接。工具只检索原文，不生成理论解释或现实分析。可按作者和作品筛选，最近检索保存在浏览器本地。

当前索引包含 **17 部中文作品、6798 个段落**，全部来自[中文马克思主义文库](https://www.marxists.org/chinese/index.html)。目前已有中文版本，因此没有对英文材料重复机器翻译；未来出现英文回退时，必须明确标记机器翻译并保留英文来源。完整收录范围、版本与定位规则见[文献来源与检索边界](docs/文献来源.md)。

内置资料采用马恩列斯毛作者白名单，不遍历或收录托派作者文献。仓库不对所收录译本作统一再许可声明；公开转发或改编前请核查原始资料和译本的适用权利。

维护者可在 Windows Git Bash 中运行 `scripts/test.sh` 验证本地页面，运行 `scripts/test-online.sh` 验证 GitHub Pages，或运行 `scripts/build.sh` 从白名单页面重建索引。脚本不引入项目依赖。
