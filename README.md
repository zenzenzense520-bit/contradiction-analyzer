# 马恩列斯毛原著定位器

输入中文关键词，定位马恩列斯毛核心文献及白名单扩展文献中的具体段落。[打开在线版本](https://zenzenzense520-bit.github.io/contradiction-analyzer/)，也可下载整个仓库后双击 `index.html` 离线使用。

结果显示作者、作品、网页标题、索引段落、中文上下文和原网页链接。工具只检索索引正文，不生成理论解释或现实分析。可按作者和作品筛选，最近检索保存在浏览器本地。

本地工作区的修改在发布前不会同步到上方在线版本。

新版提供“完整短语 / 包含全部词 / 包含任意词”三种匹配方式。多个词请用空格分隔；结果每页展示 12 条，可按命中作品继续缩小范围、展开索引中的完整段落，或复制带来源网址的定位信息。文献目录支持按作者和作品名查找。

当前索引包含 **26 部中文作品、10294 个段落**，全部来自[中文马克思主义文库](https://www.marxists.org/chinese/index.html)。扩展部分包括霍查、周恩来、胡志明、切·格瓦拉、《共产主义ABC》和毛泽东诗词。目前已有中文版本，因此没有对英文材料重复机器翻译；未来出现英文回退时，必须明确标记机器翻译并保留英文来源。完整收录范围、版本与定位规则见[文献来源与检索边界](docs/文献来源.md)。

内置资料采用作者与作品双重白名单，不遍历作者目录。构建和测试会拦截托洛茨基、第四国际、主体思想、刘少奇、铁托、邓小平相关文献。仓库不对所收录译本作统一再许可声明；公开转发或改编前请核查原始资料和译本的适用权利。

交互设计参考了 [daily-poetry 的离线检索与手机阅读](https://github.com/liumingmusic/daily-poetry)；扩充整套文献时可参考 [marxist-classics-markdown 的卷册清单](https://github.com/PrismScopes/marxist-classics-markdown)，但其 OCR 文本尚未逐卷校勘与核验权利，本项目没有直接并入。详见[本次升级记录](discuss/新版升级记录.md)。

维护者可在 Windows Git Bash 中运行 `scripts/test.sh` 验证本地页面，运行 `scripts/test-online.sh` 验证 GitHub Pages，或运行 `scripts/build.sh` 从白名单页面重建索引。脚本不引入项目依赖。
