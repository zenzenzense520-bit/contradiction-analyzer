# 矛盾分析器

浏览器内运行的文献检索与结构分析工具。可直接打开 GitHub Pages 页面，也可下载整个仓库后双击 `index.html` 离线使用；需让 `corpus.js` 和 `src/` 与入口文件保持相对位置。

目前收录《共产党宣言》《资本论》第一卷及部分列宁、斯大林著作的英文主体段落，并接入《矛盾论》《实践论》《中国社会各阶级的分析》的中文短引和来源入口。**未收录毛泽东选集、列宁全集或斯大林选集的完整卷册，也没有训练大模型。** 检索结果会标出版本、章节和原网页。中文马克思主义文库只采用指定作者与作品的入口，内置库不收录托派作者文献。

资料范围、版本和来源见 [文献来源与收录边界](docs/文献来源.md)。导入的 TXT/Markdown 与分析历史保存在浏览器本地存储，不上传到服务器。页面不会提供实时事实数据，关于现实问题的判断仍需外部证据。

本仓库不对所收录译本作统一再许可声明。公开转发或改编时，请逐一核对原始文献及译本的适用权利，并保留来源标注。

维护者可在 Windows Git Bash 中运行 `scripts/test.sh` 验证语料与 Edge 页面，或运行 `scripts/build.sh` 从已核对的来源重建索引；脚本仅使用现有的 Node.js、uv 和浏览器，不引入项目依赖。
