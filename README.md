# 马恩列斯毛原著学习

输入中文关键词，定位马恩列斯毛核心文献及白名单扩展文献中的具体段落；也可以按作品连续阅读、按专题路径系统学习、每日精读一段并打卡，或收藏重点段落、写笔记。

## 快速上手

- **在线使用**（无需安装）：直接打开 [GitHub Pages 在线版本](https://zenzenzense520-bit.github.io/contradiction-analyzer/)。
- **离线使用**：仓库页面 `Code → Download ZIP`，解压后双击 `index.html` 即可在浏览器离线使用，学习数据保存在浏览器本地。
- **本地校验与构建**（可选，维护者）：`test.sh` / `test-online.sh` / `build.sh` 等脚本用法见下方[测试](#测试)章节，脚本不引入额外依赖。

## 功能

- **原著检索**：提供“完整短语 / 包含全部词 / 包含任意词”三种匹配方式，按作者、作品筛选；结果显示作者、作品、网页位置、中文上下文与原网页链接，可展开完整段落、复制定位信息、一键收藏。
- **原著阅读**：按作品连续阅读，网页/章节导航与目录跳转，阅读进度自动保存，可随时从文献库或专题“继续阅读”。
- **专题学习**：按“入门导论、马克思主义哲学、政治经济学、科学社会主义与国家学说、帝国主义与革命战争、中国革命与建设”六个专题，给出建议阅读顺序与客观导言。
- **每日精读**：每天由日期固定从原著中选取一段，读完打卡，统计连续、累计与本月天数，可回看历史日期、补打卡。
- **我的学习**：收藏、笔记、检索历史与学习统计集中查看，全部保存在浏览器本地，离线可用。

工具只检索、呈现索引正文，不生成理论解释或现实分析。

## 索引规模

当前索引包含 **26 部中文作品、10294 个段落**，全部来自[中文马克思主义文库](https://www.marxists.org/chinese/index.html)。扩展部分包括霍查、周恩来、胡志明、切·格瓦拉、《共产主义ABC》和毛泽东诗词。所有数字来自当前索引；段落序号由本工具生成，并非纸本页码，引用前请核对原网页。完整收录范围、版本与定位规则见[文献来源与检索边界](docs/文献来源.md)。

收藏、笔记、阅读进度与打卡通过浏览器 localStorage 保存，清空浏览器数据或更换浏览器、设备会丢失，重要笔记请另行备份。

## 范围与边界

内置资料采用作者与作品双重白名单，不遍历作者目录。不提供且禁止上传托洛茨基、第四国际、主体思想、铁托相关文献。仓库不对所收录译本作统一再许可声明；公开转发或改编前请核查原始资料和译本的适用权利。目前收录的均为中文页面，没有对英文材料重复机器翻译；未来出现英文回退时，必须明确标记机器翻译并保留英文来源。

交互设计参考了 [daily-poetry 的离线检索与手机阅读](https://github.com/liumingmusic/daily-poetry)；扩充整套文献时可参考 [marxist-classics-markdown 的卷册清单](https://github.com/PrismScopes/marxist-classics-markdown)，但其 OCR 文本尚未逐卷校勘与核验权利，本项目没有直接并入。详见[升级记录](discuss/新版升级记录.md)。

## 测试

维护者可在 Windows Git Bash 中运行 `scripts/test.sh` 验证本地页面，运行 `scripts/test-online.sh` 验证 GitHub Pages，或运行 `scripts/build.sh` 从白名单页面重建索引。无 Bash 时也可直接用 Node 运行 `scripts/verify.js`（静态校验）与 `scripts/browser_smoke.js`（真实 Edge 点击）。脚本不引入项目依赖。
