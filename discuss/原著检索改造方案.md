# 原著检索改造方案

## 目标

把现有“现实问题分析”入口改为“马恩列斯毛原著定位”：用户输入中文关键词，页面返回作者、作品、章节或页面、段落序号、命中上下文和中文马克思主义文库原网页。

## 范围

1. 内置资料只采用马克思、恩格斯、列宁、斯大林、毛泽东白名单作品，不抓取托派作者页面。
2. 优先索引用户指定的中文马克思主义文库中文正文。只有缺少中文正文时才允许英语回退，并把译文明确标为机器翻译；不能冒充正式中译本。
3. 保留现有视觉风格、本地双击运行、GitHub Pages、浏览器本地历史、文献目录与来源说明。
4. 删除现实问题分析、R&L 分析、普通对话和多理论辩论入口，避免搜索工具产生看似有理论依据的自动结论。
5. 首批全文索引核心著作；作品目录明确显示实际收录范围，不把部分语料称为全集。

## 验收

- 输入“剩余价值”“国家”“实践”“主要矛盾”等关键词能返回实际中文原文。
- 每条结果显示作者、作品、位置、上下文和原网页链接。
- 无命中时明确提示，不生成答案。
- 本地 `file://` 与 GitHub Pages 均通过真实 Edge 点击测试。
