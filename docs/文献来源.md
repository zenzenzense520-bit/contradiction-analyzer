# 文献来源与收录边界

本项目是离线文本检索与规则辅助分析工具。它没有训练大模型，也没有实时抓取新闻、统计或学术数据库。浏览器从 `corpus.js` 检索原文段落，分析页把文献观点、用户定义的“革命与爱”理论、事实边界、其他视角与推论分别标明。

## 中文版本入口

用户提供的[中文马克思主义文库](https://www.marxists.org/chinese/index.html)是重要核对来源。本项目只将明确选定的马克思、恩格斯、列宁、斯大林、毛泽东作者页面或作品页面接入文献目录：

- [《共产党宣言》中文页面](https://www.marxists.org/chinese/marx/01.htm)
- [《资本论》第一卷中文目录](https://www.marxists.org/chinese/marx/capital/index.htm)
- [列宁全集中文目录](https://www.marxists.org/chinese/lenin-cworks/index.htm)
- [毛泽东选集中文目录](https://www.marxists.org/chinese/maozedong/index.htm)
- [斯大林中文作品目录](https://www.marxists.org/chinese/stalin/index.htm)

英文离线段落和中文网站是不同版本。中文链接帮助读者核对、继续阅读，不表示中文全集已被下载或建立全文索引。项目仅从上述白名单作者与作品建立内置库，**不收录托派作者文献**。用户导入文件也会拦截文件名或明确作者署名为托洛茨基等的材料；自由文本无法仅靠关键词准确判断理论流派，因此不能把此功能当作完整的思想分类器。

## 来源使用与更新

[Project Gutenberg](https://www.gutenberg.org/ebooks/61)将其《共产党宣言》电子书标记为美国公有领域。[Marxists Internet Archive 使用条款](https://www.marxists.org/admin/legal/terms-of-use.htm)说明：资料中可能有单独标记版权的作品，转载者需自行核实适用权利，并注明文库与作品网址。因此本项目保留来源链接、版本说明，并谨慎限制未明确许可的中文译本收录范围。需要分发或公开部署时，应再核查目标地区和具体译本的权利状态。

更新语料时运行 `scripts/build.sh`，检查网页来源与作者白名单，然后运行 `scripts/test.sh`。这两个脚本无需安装新的项目依赖；构建阶段使用本机已有的 `uv`，运行页面只需浏览器。生成的 `corpus.js` 与 `index.html`、`src/` 必须保存在同一文件夹内。
