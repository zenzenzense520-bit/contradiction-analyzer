# 文献来源与检索边界

本项目是以马恩列斯毛为核心、包含明确扩展白名单的中文原著定位工具。用户输入关键词或短语后，浏览器在本地索引中查找真实段落，返回作者、作品、网页位置、索引段落和原网页链接。它不回答现实问题，不生成理论结论，也不把搜索结果自动解释为作者的完整观点。

## 中文与翻译

当前收录页面本身已有中文文本，因此页面直接显示中文文库版本，没有把既有英文索引再自动翻译。数据结构保留了 `language` 和 `translation` 字段：未来只有在中文文库确实没有中文正文时，才能加入英文回退；翻译结果必须标记“机器翻译”，并同时保留英文原段和英文来源，不能冒充正式中译本。

## 作者范围

内置资料严格限定为上表作者和逐篇列明的作品。构建脚本不遍历中文文库首页或整个作者目录，并在生成索引及测试时检查作者、作品名和来源网址。禁止收录托洛茨基、第四国际、主体思想、刘少奇、铁托、邓小平相关文献；正文中对这些人物或概念的历史性提及不会被当成一篇禁入文献。白名单是一项产品范围，不代表对文库其他资料的真实性或学术价值作出判断。

## 定位方法

每个索引项记录：作者、作品、网页标题、作品内网页序号、网页内索引段落序号、正文和来源网址。“索引第几段”是本工具为了定位而生成的顺序号，不是出版社版本的自然段编号或页码。引用前应点击“打开中文马克思主义文库原网页”，核对上下文、注释和具体版本。

## 来源使用

[Marxists Internet Archive 使用条款](https://www.marxists.org/admin/legal/terms-of-use.htm)说明，文库无法对所有资料的法律状态作统一保证，部分材料可能另有版权标记；复制资料时应注明文库和作品网址。公开转发、出版或制作衍生版本时，应逐项核查原著、译本和适用地区的权利状态。

维护者可运行 `scripts/build.sh` 从白名单网址重建索引，随后运行 `scripts/test.sh`。页面运行不需要后端服务；`corpus.js`、`src/` 和 `index.html` 必须保持相对位置。
